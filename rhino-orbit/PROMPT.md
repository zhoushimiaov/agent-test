# 犀牛绕地球 — 任务提示词

考点(对应 `build.mjs` 的 `exam`):环绕轨道的运动曲线、犀牛与地球的尺度关系,以及公转节奏的表达。

## 交给模型的提示词

```text
用一个单独的 HTML 文件,做一个「一头犀牛绕着地球公转」的动画场景。

交付要求:
- 全部代码(HTML / CSS / JS)写在同一个文件内,双击即可在浏览器打开运行,自动循环播放,无需任何交互。
- 技术方案自选:纯 CSS/JS 2D 动画,或 Three.js / WebGL 3D 都可以;需要第三方库就用 CDN 引入。
- 画面不要有操作说明或控件,打开就是成品。

犀牛和地球怎么画、两者的大小比例、轨道是圆是椭圆、要不要星空背景、公转速度和运镜,全部由你自己判断,做出你认为最有说服力的一版。
```

## 设计说明(不给模型)

- 只写死机械约束(单文件 / 打开即跑 / 循环 / 无交互),配合本仓库的对比流程与 headless Chrome 截图。产物落在 `rhino-orbit/` 下,文件名 `*-modelname.html`。
- 刻意留白的三点正好对应三个评分维度:犀牛/地球的**尺度比例**、绕行的**轨道曲线**、**公转节奏**与运镜。题干不提示,才能看出哪个模型自己想到了「犀牛相对地球应极小」「轨道应有近大远小/遮挡的透视感」「公转匀速还是带缓动」。
- 「技术方案自选」本身是考点:强模型会判断 3D(Three.js 做公转/遮挡)比 2D 更出彩。若要分出 2D 组 / 3D 组各自横评(像鹈鹕题的 `-3d` 后缀版本),把最后留白段改成「必须用 Three.js / WebGL 实现」再单独跑一轮。
