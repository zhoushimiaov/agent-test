# 森林小屋（Forest Cabin）— 公开复刻评测题面 v1

> **来源说明**：依据仓库中 `jev-score-forest-cabin.mjs` 的 TASK、Rubric 和栏目说明整理为可重跑的单 HTML 题面。仓库未存有历史模型的完整输入对话或经确认的原建筑图纸，不应声称逐字复现历史输入。

## 在 Playground 使用的提示词

```text
请用一个单独的 HTML 页面，制作一个可观察、可漫游的建筑空间展示：受彼得·卒姆托在瑞士的 Leis Houses（莱斯木屋）启发的阿尔卑斯山谷木屋。

重点是建筑构造和空间光线，而非装饰：
- 表现传统 Strickbau 叠木墙体：成层水平实木构件、转角交接、木料厚度和接缝阴影；底部有石砌基座，屋面为较低坡度的人字屋顶，门窗有明确洞口与尺度关系。
- 木材、石材具有合理的纹理、粗糙度和厚度感；避免只有平板贴图的空心盒子。
- 通过日光穿过门窗的方向性光线、室内明暗层次，以及山谷中的自然环境表达沉静的建筑氛围。
- 至少提供一个建筑整体观察视角和一个室内观察视角；可以使用相机漫游、切换视角、热点说明或环境光调节，但控件应真实有效。
- 这是面向浏览器的建筑展示，不得宣称模型几何和尺寸是对原建筑的测绘级复制。

交付要求：仅输出一个 HTML 文件，所有页面逻辑可运行，CSS / JavaScript 可内嵌；如需 Three.js 可通过公共 CDN 引入。不要依赖本地文件、密钥或后端服务。页面应可在受限 iframe 沙箱中交互。
```
