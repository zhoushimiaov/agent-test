# 章鱼打架子鼓 — 任务提示词

考点(对应 `build.mjs` 的 `exam`):八条腕到各鼓件的合理分配与节奏协调 —— 最能拉开模型差距的难点。

## 交给模型的提示词

```text
用一个单独的 HTML 文件,做一个「一只章鱼在打架子鼓」的动画场景。

交付要求:
- 全部代码(HTML / CSS / JS)写在同一个文件内,双击即可在浏览器打开运行,自动循环播放,无需任何交互。
- 技术方案自选:纯 CSS/JS 2D 动画,或 Three.js / WebGL 3D 都可以;需要第三方库就用 CDN 引入。
- 画面不要有操作说明或控件,打开就是成品。

鼓组怎么摆、章鱼的造型、八条腕怎么分配、鼓点的节奏、要不要音符或打击特效、以及运镜,全部由你自己判断,做出你认为最有说服力的一版。
```

## 设计说明(不给模型)

- 只写死机械约束(单文件 / 打开即跑 / 循环 / 无交互),配合本仓库的对比流程与 headless Chrome 截图。产物落在 `octopus-drummer/` 下,文件名 `*-modelname.html`。
- 刻意留白对应评分维度:**八条腕到鼓 / 镲 / 踩锤的合理分配**(每条腕有明确去向、不打架、不穿模)、以及**击打与节奏的协调**(腕的下落要对上鼓点)。这是全系列最容易翻车、最能区分模型的一题。
- 技术分化点:难点在肢体协调而非渲染方式——2D/3D 都行;重点看模型能不能把 8 条腕的运动规划清楚,弱模型通常会腕子乱缠或打空。
