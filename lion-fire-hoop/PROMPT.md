# 狮子跳火圈 — 任务提示词

考点(对应 `build.mjs` 的 `exam`):起跳到落地的抛物线轨迹、火圈的粒子效果,以及穿圈与落地时机的配合。

## 交给模型的提示词

```text
用一个单独的 HTML 文件,做一个「一头狮子跃过火圈」的动画场景。

交付要求:
- 全部代码(HTML / CSS / JS)写在同一个文件内,双击即可在浏览器打开运行,自动循环播放,无需任何交互。
- 技术方案自选:纯 CSS/JS 2D 动画,或 Three.js / WebGL 3D 都可以;需要第三方库就用 CDN 引入。
- 画面不要有操作说明或控件,打开就是成品。

狮子的造型、火圈的大小与位置、火焰效果的强弱、助跑与落地的处理、背景和运镜,全部由你自己判断,做出你认为最有说服力的一版。
```

## 设计说明(不给模型)

- 只写死机械约束(单文件 / 打开即跑 / 循环 / 无交互),配合本仓库的对比流程与 headless Chrome 截图。产物落在 `lion-fire-hoop/` 下,文件名 `*-modelname.html`。
- 刻意留白对应评分维度:起跳—过圈—落地的**抛物线轨迹**(符合重力、顶点在火圈处)、**火圈的粒子/火焰效果**、以及**穿圈与落地的时机配合**(狮子正好在空中穿过圈心,不早不晚)。
- 技术分化点:核心是**动画时序**而非渲染——时间轴一旦没对齐,就会出现"人到了圈还没到"或穿模,是最容易翻车的点。2D/3D 均可,重点考时间编排和粒子表现。
