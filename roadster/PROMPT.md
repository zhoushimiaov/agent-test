# 太空飞车（Roadster）— 公开复刻评测题面 v1

> **来源说明**：根据仓库现存的 `jev-score-roadster.mjs` 中 TASK、评分维度与栏目介绍整理的**可重跑公开题面**，不是历史 9 个作品原始逐字 Prompt 的证明。历史作品包含“轨道漂浮”和“冷气推进起降”不同实现分支，比较时应明确区分。

## 在 Playground 使用的提示词

```text
请用一个完整、可独立打开的 HTML 文件，制作 3D 互动或自动动画场景：SpaceX 送入太空的樱桃红 Tesla Roadster，以及坐在驾驶座上的宇航员 Starman。

必须表现：
- 低矮跑车车身、前后比例、轮胎和敞篷座舱清晰可辨；Starman 戴头盔、穿宇航服，以放松姿势坐在驾驶位置，至少一只手靠近方向盘。
- 太空空间感：地球曲率、星空背景以及来自单一方向的太阳光与暗面。
- 连续的、可观察的运动。可选 A：真空中的慢速惯性漂移／翻滚；或 B：采用冷气推进器的垂直起飞、机动、软着陆。请在页面内标识使用的运动方案，不要把没有运动的静态模型冒充仿真。

交付要求：仅输出单个 HTML 文档的源代码，CSS 与 JavaScript 可以内嵌；如需 Three.js 可以使用公开 CDN。不得依赖本地文件路径、登录信息、密钥或后端服务。页面必须能在受限 iframe 沙箱中运行。
```

## 评测说明（不发送给模型）

- 本题的 Roadster 运动路线 A/B 是两种实现分支；原有榜单将两种作品放在一起，**不是严格同一物理条件下的横向比较**。
- 在线 Jev Rubric 与离线排行榜脚本共用 `worker/src/engineering-rubrics.js`，维度为整车还原 30、Starman 姿态 25、太空场景 20、飞行动力学 25。
- 评分结果若只分析源代码，不能推断真实动画质量；单帧截图也不能验证运动轨迹。历史评分不因本文更新而自动失效或重算。
