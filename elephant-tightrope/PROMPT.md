# 大象走钢丝 — 任务提示词

考点(对应 `build.mjs` 的 `exam`):重量感与平衡杆的配重、钢丝受力下垂的张力曲线,反差越大越见功力。

## 交给模型的提示词

```text
用一个单独的 HTML 文件,做一个「一头大象踩在钢丝上保持平衡」的动画场景。

交付要求:
- 全部代码(HTML / CSS / JS)写在同一个文件内,双击即可在浏览器打开运行,自动循环播放,无需任何交互。
- 技术方案自选:纯 CSS/JS 2D 动画,或 Three.js / WebGL 3D 都可以;需要第三方库就用 CDN 引入。
- 画面不要有操作说明或控件,打开就是成品。

大象的造型、钢丝的长度与高度、平衡杆的样子、要不要晃动与风、背景和运镜,全部由你自己判断,做出你认为最有说服力的一版。
```

## 设计说明(不给模型)

- 只写死机械约束(单文件 / 打开即跑 / 循环 / 无交互),配合本仓库的对比流程与 headless Chrome 截图。产物落在 `elephant-tightrope/` 下,文件名 `*-modelname.html`。
- 刻意留白对应评分维度:庞大身躯的**重量感**、**平衡杆**作为配重的物理暗示(微微摆动找平衡)、以及钢丝**受力下垂的张力曲线**(大象脚下应明显凹陷成悬链线)。反差越强越见功力。
- 技术分化点:钢丝下垂曲线和重量微晃是 2D 关键帧也能做好的"物理直觉"考题,不必强依赖 3D;看模型是否想到"重物压钢丝会垂"这个细节,是最直接的区分点。
