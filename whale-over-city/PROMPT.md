# 鲸鱼在城市上空游泳 — 任务提示词

考点(对应 `build.mjs` 的 `exam`):超现实的尺度对比,以及鲸身与云层之间正确的前后遮挡(z 轴层叠)关系。

## 交给模型的提示词

```text
用一个单独的 HTML 文件,做一个「一头巨鲸在城市上空游动」的动画场景。

交付要求:
- 全部代码(HTML / CSS / JS)写在同一个文件内,双击即可在浏览器打开运行,自动循环播放,无需任何交互。
- 技术方案自选:纯 CSS/JS 2D 动画,或 Three.js / WebGL 3D 都可以;需要第三方库就用 CDN 引入。
- 画面不要有操作说明或控件,打开就是成品。

鲸鱼的大小、城市的样貌、云层的多少与高低、游动的路线和运镜,全部由你自己判断,做出你认为最有说服力的一版。
```

## 设计说明(不给模型)

- 只写死机械约束(单文件 / 打开即跑 / 循环 / 无交互),配合本仓库的对比流程与 headless Chrome 截图。产物落在 `whale-over-city/` 下,文件名 `*-modelname.html`。
- 刻意留白对应评分维度:**超现实尺度对比**(鲸相对楼宇要足够夸张)、以及最关键的**鲸身穿云的前后遮挡**——云应有的在鲸前、有的在鲸后,z 轴层叠正确才有"穿行"感,一刀切全前或全后就露馅。
- 技术分化点:2D 靠分层 z-index 和局部蒙版硬凑遮挡;3D 靠真实深度排序自动成立。留白能看出模型是否意识到遮挡是本题核心难点。
