# 水母漂浮 — 任务提示词

考点(对应 `build.mjs` 的 `exam`):半透明材质的层叠、触手的柔体摆动,以及水下光线的衰减与散射。

## 交给模型的提示词

```text
用一个单独的 HTML 文件,做一个「一只水母在水中漂浮」的动画场景。

交付要求:
- 全部代码(HTML / CSS / JS)写在同一个文件内,双击即可在浏览器打开运行,自动循环播放,无需任何交互。
- 技术方案自选:纯 CSS/JS 2D 动画,或 Three.js / WebGL 3D 都可以;需要第三方库就用 CDN 引入。
- 画面不要有操作说明或控件,打开就是成品。

水母的伞体形状和颜色、触手的数量与长度、水的深浅与光感、漂浮的快慢和运镜,全部由你自己判断,做出你认为最有说服力的一版。
```

## 设计说明(不给模型)

- 只写死机械约束(单文件 / 打开即跑 / 循环 / 无交互),配合本仓库的对比流程与 headless Chrome 截图。产物落在 `jellyfish-float/` 下,文件名 `*-modelname.html`。
- 刻意留白对应三个评分维度:半透明材质的**层叠通透感**、触手的**柔体律动**(是否有相位差、不是整体刚性平移)、水下**光线穿透与衰减/散射**。题干不点破,才看得出哪个模型主动想到透明度叠加和光束。
- 技术分化点:2D 靠半透明 + 模糊/滤镜 + 关键帧摆动;3D 可做真实折射与体积光。可留白让模型自己选,也可强制 Three.js 单独跑一轮横评。
