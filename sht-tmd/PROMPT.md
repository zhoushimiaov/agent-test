```text
请用一个完整的 HTML 文件，实现“上海中心大厦顶部电涡流摆式调谐质量阻尼器（TMD）”的实时可视化演示，兼顾建筑模型、阻尼器构造、台风作用下的运动和数据面板。

建筑与装置参考约束（以下为本题的简化描述，不是可用于真实工程设计的图纸）：
- 上海中心为高度约 632 m、随高度扭转约 120° 的圆角三角形高层建筑，外立面有双层玻璃幕墙。
- 观景层附近的摆式阻尼器表现为约千吨级悬挂质量块；画面应有偏高的红色主体质量块、顶部固定主梁及多根吊索（可参考约 12 根）、金色展示门架、若干随摆伸缩的斜向耗能／限位装置，并能体现“上海慧眼”装饰装置与阻尼器设备的区别。
- 台风作用时，塔体发生侧移／摆振，质量块与塔体表现出相对运动和相位差；提供从平静、风力增大、响应峰值到减振／失谐的演示阶段。展示位移、阻尼器行程和减振率等数据；数据必须与演示状态关联，禁止纯随机数字冒充工程计算。
- 可选择构造剖面、内部机房和建筑整体等视角；配备可实际改变风力或阻尼参数的界面控件。可在场景中加入黄浦江及陆家嘴周边地标，但应把设备构造与运动作为主要内容。
- 若使用简化运动方程，请在界面上注明为概念性演示，不得声称为真实结构动力计算或工程安全评估。

交付要求：只输出一个自包含 HTML 文档。CSS 与 JavaScript 内嵌；可以从公共 CDN 加载 Three.js，但不得依赖本地文件、私有图纸地址、API Key 或远程后端。页面必须能在受限 iframe 沙箱中运行。
```
