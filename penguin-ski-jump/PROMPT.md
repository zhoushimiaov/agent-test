# 企鹅滑雪跳台 — 任务提示词

考点(对应 `build.mjs` 的 `exam`):斜坡与腾空的抛物线、落地缓冲,以及 3D 相机跟随与投影阴影的实时变化。

## 交给模型的提示词

```text
用一个单独的 HTML 文件,做一个「一只企鹅冲下滑雪跳台、腾空再落地」的动画场景。

交付要求:
- 全部代码(HTML / CSS / JS)写在同一个文件内,双击即可在浏览器打开运行,自动循环播放,无需任何交互。
- 技术方案自选:纯 CSS/JS 2D 动画,或 Three.js / WebGL 3D 都可以;需要第三方库就用 CDN 引入。
- 画面不要有操作说明或控件,打开就是成品。

企鹅的造型、跳台的坡度与高度、腾空的幅度、相机怎么跟拍、要不要雪花和远景,以及整体节奏,全部由你自己判断,做出你认为最有说服力的一版。
```

## 设计说明(不给模型)

- 只写死机械约束(单文件 / 打开即跑 / 循环 / 无交互),配合本仓库的对比流程与 headless Chrome 截图。产物落在 `penguin-ski-jump/` 下,文件名 `*-modelname.html`。
- 刻意留白对应评分维度:下坡—腾空的**抛物线轨迹**是否符合物理、**落地缓冲**(不是硬着陆)、**相机跟随**的连续性、以及**投影阴影随高度实时变化**(腾空时影子变淡变大)。
- 技术分化点:这题 3D 天然吃香——相机跟拍和实时投影阴影在 2D 里极难表现,弱模型往往退化成贴图平移。建议默认留白看模型会不会主动上 3D,再强制 Three.js 单独跑一轮做对照组。
